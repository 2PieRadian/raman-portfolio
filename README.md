# Raman Bhardwaj — Portfolio

A React + Vite portfolio based on the supplied resume and the visual references.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Notes
- All resume content and external links are included in the site.
- Layout is responsive for desktop, tablet, and mobile.
- Uses React, Vite, Lucide icons, and plain CSS.
- Google Fonts are loaded from Google Fonts; install locally or replace if you need a fully offline build.
